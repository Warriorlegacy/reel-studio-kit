# Instagram Reel topic brief

**Format:** 9:16, 1080×1920, Hindi voiceover, about 35 seconds.

## Topic options

1. **Selected:** “एक तस्वीर की GIF बनी—अब आखिरी frame match होगा?” — show a still image turn into a loop, then reveal the one loop prompt detail viewers should check.
2. “AI chatbot vs AI agent” — a simple everyday example of an assistant that can use connected tools.
3. “AI images अब छोटी animation भी बना सकती हैं?” — show the difference between an image, a GIF loop, and a full video.

The first topic is the freshest visual story: OpenAI announced Images 2.6 and GIF generation on 4 November 2026. The script describes the feature without claiming it is free or available to every account.

## Hook candidates

1. AI से तस्वीर की GIF बन सकती है—पर आखिरी frame गलत हुआ, तो loop झटकेगा.
2. Static photo से GIF? आखिरी frame वाला छोटा trick देखो.
3. एक prompt, और तस्वीर हिलने लगे? Loop smooth तभी होगा जब आखिरी pose वापस आए.
4. AI से GIF बनाना आसान—लेकिन loop में jump क्यों दिखता है?
5. अपनी photo को चलाने से पहले prompt में ये तीन बातें लिखो.

**Selected spoken hook:** “AI से तस्वीर की GIF बन सकती है—पर आखिरी frame गलत हुआ, तो loop झटकेगा. इसे smooth कैसे रखें?”

## Voiceover script

AI से तस्वीर की GIF बन सकती है—पर आखिरी frame गलत हुआ, तो loop झटकेगा. इसे smooth कैसे रखें? OpenAI Images 2.6 में GIF generation जोड़ी गई है.

मान लो तुम्हारा mascot हाथ हिलाता है. Prompt में तीन बातें लिखो: क्या हिले, movement कैसी हो, और कहाँ जाकर loop शुरू वाली pose पर लौटे.

Example: “कप से भाप धीरे ऊपर उठे, कैमरा स्थिर रहे, भाप फिर पहली shape में लौटे.”

बस, trick आखिरी line है: end pose पहली frame जैसी. नहीं तो loop पर झटका दिखेगा.

ध्यान रहे, GIF छोटा repeating clip है—पूरा edited video नहीं. Generate करने के बाद loop देखो.

अब बताओ, तुम किस चीज़ को animate करोगे?

**CTA:** Comment “GIF”.

**Estimated length:** 85 spoken words; about 34 seconds at 150 wpm, plus pauses.

## Retention and visual beats

- **0–2s:** Start on a still mug illustration; steam moves before the first sentence ends.
- **2–7s:** The still card flips into a short looping GIF card. Say exactly what changed.
- **7–15s:** Three prompt pieces land one by one: subject, movement, return pose.
- **15–24s:** Show a mug releasing steam with a fixed camera; the steam returns to its first silhouette.
- **24–30s:** Compare a mismatched end frame (visible jump) with a matching start/end pose.
- **30–35s:** Ask what viewers would animate; return to the still mug composition for a clean loop.

## Fact limits

- Images 2.6 supports GIF generation; a GIF is a short repeating animation, not a finished long-form edit.
- The loop instruction is a practical prompt-writing tip from OpenAI’s image prompting guide, not a promise that every generation loops perfectly.
- Check the finished GIF for a visible jump before publishing.
